BROADWAYCPU STAGE 4 - INSTRUCTION COVERAGE NOTES
================================================

This is a partial interpreter implementation for the 32-bit PowerPC / Gekko
family. It is not a complete or validated IBM 750CL implementation.

Implemented families (coverage varies by encoding and edge case):
- D-form integer arithmetic/logical immediates and compare immediates.
- Rotate/mask word operations.
- Selected X-form arithmetic, carry, overflow, multiply/divide, shifts,
  sign extension, logical operations and count-leading-zero.
- CR field compare/move and common CR boolean operations.
- Unconditional, conditional, LR and CTR branch forms.
- D-form integer loads/stores, multiple-word transfers and common indexed
  byte/halfword/word load/store forms.
- String word loads/stores (LSWI/LSWX/STSWI/STSWX; test additional encodings).
- Basic SPR access for XER, LR and CTR.
- Scalar floating-point arithmetic, compares and basic FP memory forms.
- Selected Gekko paired-single arithmetic/merge forms.

Known incomplete / not validated:
- Full PowerPC 750CL opcode matrix and exact invalid-encoding rules.
- PSQ quantized paired-single loads/stores and full GQR semantics.
- Complete FPSCR sticky flags, exception enables, rounding modes and NaN rules.
- Full SPR, segment-register, BAT, SDR1, MMU and TLB instruction behaviour.
- Correct cache, reservation, memory-coherency and bus semantics.
- Complete exception delivery/vectoring, privilege checks and MSR transitions.
- Cycle timing, interrupts, external signals, and Wii hardware integration.
- Instruction-specific corner cases and full architecture test-suite validation.

A passing local regression suite only proves the included test cases. It does
not establish compatibility with Wii software. Keep unimplemented instructions
as explicit exceptions rather than silently treating them as successful NOPs.
