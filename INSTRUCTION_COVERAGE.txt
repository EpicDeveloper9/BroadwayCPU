BROADWAYCPU INSTRUCTION COVERAGE NOTES
=====================================

This is an in-progress 32-bit Broadway/Gekko-derived PowerPC interpreter. The
core is not a complete or validated IBM 750CL implementation. Build success
and passing tests only verify the implemented source paths and test vectors.

Implemented and tested portions currently include:
- Selected D-form integer arithmetic/logical immediates, compares and
  rotate/mask operations.
- Selected X-form arithmetic, carry/overflow, multiply/divide, shifts, sign
  extension, logical operations and CR boolean operations.
- Direct, conditional, LR and CTR branch forms.
- Integer D-form and indexed memory operations, string transfers, and
  byte-reversed indexed operations.
- Scalar floating-point arithmetic, comparisons, displacement and selected
  indexed memory operations.
- Selected paired-single arithmetic, merge, comparisons, and quantized
  operations using GQR state.
- Privileged MSR operations, rfi, selected SPRs, segment registers, GQR/HID2,
  SPRG, BAT register storage, and externally clocked time-base state.

Important incomplete architectural behavior:
- Broad instruction encoding and reserved-field coverage is incomplete.
- FPSCR exception flags/enables and several IEEE-754 corner cases need a full
  architecture audit. Reciprocal estimates and conversion edge cases need
  independently sourced reference vectors.
- BAT values are stored but are not used for effective-to-physical address
  translation. Page-table/TLB translation, protection, and MMU exceptions are
  not implemented.
- Exception conditions are reported to the host as CPUException objects;
  architectural exception entry, vectoring, SRR capture, DAR/DSISR updates,
  priority and interrupt delivery remain incomplete.
- Cache operations, reservation/coherency behavior, and bus-visible ordering
  are not modeled. The flat memory array is not a hardware memory subsystem.
- Time-base state can be read and written, but the emulated system must clock
  it; no bus-clock-derived time base or decrementer interrupt is implemented.
- Unsupported SPR/TBR selectors remain explicit exceptions. Not every Gekko
  implementation register has state or semantics.
- Dynamic executable modules have not been comprehensively identified or
  loaded, and Wii hardware services are not implemented by this CPU core.

The Guitar Hero III static scan is documented in
GH3_RGHP52_STATIC_ANALYSIS.md. Static DOL word counts can include embedded
data and do not prove runtime execution. Keep architectural gaps explicit;
do not silently treat an unimplemented instruction as a successful no-op.
